# 🌤️ Weather App

A simple and responsive **Weather Application** built with **HTML**, **CSS**, and **Vanilla JavaScript**.  
It allows users to search for any city and instantly see the **current weather conditions**, using a public weather API.  
Icons and visuals are displayed using **Font Awesome** and custom images for a clean, modern look.

---

## 🚀 Live Demo
🔗 [View the App on GitHub Pages](https://omargamal-og.github.io/Weather-App/)

---

## ✨ Features
- 🔍 Search for any city and get instant weather updates  
- 🌡️ Display temperature, humidity, and weather condition  
- 🌄 Dynamic weather icons using **Font Awesome** and images  
- 📱 Fully responsive layout for all devices  
- 💾 Fast and lightweight (Vanilla JavaScript, no frameworks)

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **Font Awesome**
- **Weather API**
- **Images / Icons**

## 🚀 Future Improvements

Here are some planned and possible enhancements to improve the Weather App in the future:

### 🌦 Add 5-Day Forecast
Display upcoming weather conditions using extended API data, giving users a better overview of upcoming days.

### 🌍 Detect User Location
Automatically fetch and display weather data for the user’s current location using the **Geolocation API**.

### 💡 Better Error Handling
Show clear and friendly messages for invalid cities, empty inputs, or network/API errors.

### 🌓 Dark & Light Mode
Add a toggle switch that allows users to change between light and dark themes for better accessibility and comfort.

### 📱 Responsive Design
Ensure the app looks and works perfectly across all screen sizes — mobile, tablet, and desktop.

### 💾 Save Last Search
Use **localStorage** to remember the user’s last searched city so the app loads it automatically next time.

### ⚡ Performance Optimization
Improve loading speed by minifying JavaScript and CSS, compressing images, and using caching.

### 📈 Weather Charts
Use **Chart.js** or a similar library to visualize temperature and humidity trends in simple graphs.

### 🗣 Multi-Language & Unit Support
Let users select their preferred language and switch between **°C** and **°F**.

### 🧭 UI Animations
Add smooth transitions when updating the weather info to make the experience more dynamic and modern.

### 🧪 Automated Deployment
Set up **GitHub Actions** to automatically deploy new changes to GitHub Pages whenever you push updates.

### 🧰 Code Refactoring
Split your JavaScript into smaller, modular files for cleaner structure and easier maintenance.
